# Wife Beta Start Guide

Thank you for helping test ServicesOS. This test is not about being perfect. It is about finding what is confusing, broken, missing, or not useful before anyone else sees it.

## What You Are Testing

You are testing whether ServicesOS could help run a real cleaning job from start to finish.

Please focus on:

- Creating or reviewing a customer.
- Understanding the job details.
- Following the cleaning workflow.
- Seeing what the cleaner needs to know.
- Checking whether the owner can tell what happened.
- Noticing anything confusing or annoying.

## What to Ignore for Now

Please do not worry about:

- Perfect design.
- Final pricing.
- Public launch readiness.
- Tap to Pay.
- Future products.
- Advanced reports.
- Any feature that does not affect running a basic cleaning job.

Tap to Pay is later. This test is mainly about the core workflow.

## How to Report Confusion

If something is confusing, write down:

- What screen you were on.
- What you were trying to do.
- What you expected to happen.
- What made you pause.
- What label, button, or instruction would have helped.

## How to Report Bugs

If something breaks, write down:

- What you clicked or typed right before it broke.
- What happened.
- What you expected.
- Whether you could keep going.
- Whether the issue happened again after retrying.

If possible, take a screenshot or short video.

## What to Do if Something Breaks

If something blocks you:

1. Stop the test at that step.
2. Write down what happened.
3. Tell Jamie what you were trying to do.
4. Do not keep forcing the flow unless Jamie asks you to retry.

## Questions Jamie Needs Answered

- Could you run a real cleaning job with this?
- What step confused you?
- What felt unnecessary?
- What would save you time?
- What would make you not want to use it?
- What must be fixed before showing another cleaning business?

## Final Notes

Honest feedback is the goal. If something feels annoying, too complicated, or easy to misunderstand, write it down. That is exactly what this beta is for.
