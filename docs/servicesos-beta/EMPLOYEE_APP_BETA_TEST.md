# Employee App Beta Test

Use this checklist to test the cleaner/employee workflow. The goal is to confirm that a cleaner can understand the assigned job, complete the work, and update the owner/admin without needing repeated manual instructions.

- Tester:
- Date/time:
- Device/browser:
- Employee test account:
- Assigned job:

## Employee Workflow Steps

### 1. Cleaner Login

- [ ] Open the employee app or employee login route.
- [ ] Enter cleaner credentials.
- [ ] Confirm login succeeds.
- [ ] Confirm the employee lands on the correct job list or home screen.

### 2. View Assigned Job

- [ ] Confirm assigned job appears.
- [ ] Open the assigned job.
- [ ] Confirm job date/time is visible.
- [ ] Confirm customer or service location is visible if expected.
- [ ] Confirm job status is understandable.

### 3. View Customer Notes

- [ ] Find customer notes.
- [ ] Confirm notes are readable.
- [ ] Confirm important warnings, preferences, or access details are visible if available.

### 4. View Job Instructions

- [ ] Find job instructions.
- [ ] Confirm scope of work is clear.
- [ ] Confirm special instructions are easy to understand.
- [ ] Confirm missing instructions are obvious enough to report.

### 5. Mark Arrival

- [ ] Use the arrival/check-in action if available.
- [ ] Confirm arrival status saves.
- [ ] Confirm admin/owner view can see arrival status if available.

### 6. Take Before Photos If Available

- [ ] Open before photo action if available.
- [ ] Add before photos.
- [ ] Confirm upload or save succeeds.
- [ ] Confirm photos remain attached after refresh or navigation.

### 7. Open Checklist

- [ ] Open job checklist.
- [ ] Confirm checklist items are readable.
- [ ] Confirm checklist is specific enough for the job type.
- [ ] Confirm long checklists remain usable on mobile.

### 8. Mark Checklist Items Complete

- [ ] Mark one checklist item complete.
- [ ] Mark multiple checklist items complete.
- [ ] Confirm completed state is clear.
- [ ] Navigate away and back.
- [ ] Confirm completed items remain saved.

### 9. Open SOP / Help Link If Stuck

- [ ] Open SOP, help, or training link if available.
- [ ] Confirm the link opens correctly.
- [ ] Confirm it helps the cleaner understand the task.
- [ ] Confirm returning to the job is easy.

### 10. Add Notes / Issues

- [ ] Add a job note.
- [ ] Add an issue or exception if available.
- [ ] Save note/issue.
- [ ] Confirm admin/owner can see the note or issue.

### 11. Take After Photos If Available

- [ ] Open after photo action if available.
- [ ] Add after photos.
- [ ] Confirm upload or save succeeds.
- [ ] Confirm photos remain attached after refresh or navigation.

### 12. Mark Job Complete

- [ ] Use the job complete action.
- [ ] Confirm any required checklist, photo, or note requirements are clear.
- [ ] Confirm completion saves.
- [ ] Confirm completed state is visible.

### 13. Confirm Admin Status Update

- [ ] Log in as admin/owner.
- [ ] Open the job.
- [ ] Confirm arrival status is visible if tested.
- [ ] Confirm notes/issues are visible.
- [ ] Confirm checklist completion is visible if available.
- [ ] Confirm before/after photos are visible if tested.
- [ ] Confirm job complete status is visible.

## Pass / Fail Summary

- [ ] Employee workflow passed end-to-end.
- [ ] Employee workflow passed with minor issues.
- [ ] Employee workflow blocked.
