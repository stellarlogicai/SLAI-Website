# Wife Beta Blockers

Use this checklist to decide whether wife beta can continue. If any active tested workflow hits one of these blockers, record it in the bug fix queue and resolve or document a clear workaround before continuing.

## Login / Loading

- [ ] Cannot log in.
- [ ] Tenant/account data cannot load.
- [ ] App opens to a blank or unusable screen.
- [ ] Wrong business/account data appears.

## Core Owner Workflow

- [ ] Cannot create customer/lead.
- [ ] Cannot create estimate.
- [ ] Cannot move estimate into contract/booking.
- [ ] Cannot schedule job.
- [ ] Cannot assign employee.
- [ ] Data disappears after refresh.
- [ ] Dashboard status/counts are misleading enough to break testing.

## Employee Workflow

- [ ] Employee cannot log in.
- [ ] Employee cannot see assigned job.
- [ ] Employee cannot view customer notes or job instructions.
- [ ] Employee cannot complete checklist.
- [ ] Employee cannot mark job complete.
- [ ] Job completion does not update admin.
- [ ] Admin cannot verify job progress.

## Payment / Status Clarity

- [ ] Payment status is misleading.
- [ ] Job status is misleading.
- [ ] Payment wording implies untested payment collection is live.
- [ ] Payment status cannot be documented for the tested job.

## Usability

- [ ] App is too confusing to complete a basic job.
- [ ] Tester cannot tell what to do next in the core workflow.
- [ ] Required actions are hidden or unclear.
- [ ] Mobile view blocks normal testing.

## Decision

- [ ] Wife beta can continue.
- [ ] Wife beta can continue with documented workaround.
- [ ] Wife beta should pause until blockers are fixed.
