# ServicesOS Beta Exit Criteria

Use this checklist before moving from wife beta to wider customer testing.

## Required Before Wider Testing

- [ ] Core workflow works end-to-end.
- [ ] Employee workflow is usable.
- [ ] No beta-blocking bugs remain open.
- [ ] Confusing UI items are documented.
- [ ] Payment flow status is documented.
- [ ] Known limitations are listed.
- [ ] Wife beta feedback is reviewed.
- [ ] Next fix list is created.

## Core Workflow Readiness

- [ ] Owner/admin login works.
- [ ] Dashboard loads reliably.
- [ ] Customer/lead creation works.
- [ ] Lead status updates work.
- [ ] Estimate workflow works.
- [ ] Contract/booking flow works or known limitations are documented.
- [ ] Scheduling works.
- [ ] Employee assignment works.
- [ ] Job completion works.
- [ ] Dashboard counts are accurate enough for beta.
- [ ] Logout works.

## Employee Workflow Readiness

- [ ] Cleaner login works.
- [ ] Assigned jobs are visible.
- [ ] Customer notes are visible.
- [ ] Job instructions are clear.
- [ ] Checklist flow is usable.
- [ ] Notes/issues can be submitted if available.
- [ ] Job completion status is visible to admin/owner.

## Payments Readiness

- [ ] Payment flow status is clearly documented.
- [ ] Stripe/Stripe Connect readiness is known.
- [ ] Deposit and final payment testing status is documented if available.
- [ ] Failed payment or incomplete payment behavior is documented if tested.
- [ ] Tap to Pay remains later until core workflow and payments are stable.
