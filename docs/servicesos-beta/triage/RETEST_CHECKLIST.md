## Retest Steps

- [ ] Re-run failed scenario.
- [ ] Confirm original bug is fixed.
- [ ] Confirm no new bug was introduced.
- [ ] Test on desktop.
- [ ] Test on mobile/tablet if relevant.
- [ ] Verify data persists after refresh.
- [ ] Verify admin and employee views agree when both are involved.
- [ ] Verify job status is clear.
- [ ] Verify payment status is clear if payment status was involved.
- [ ] Update bug status.
- [ ] Add fix notes.
- [ ] Add retest result.

## Wife Beta Readiness

- [ ] Blocker items are cleared.
- [ ] Beta-critical items are cleared or have approved workarounds.
- [ ] Known limitations are documented.
- [ ] Tap to Pay remains later and is not required for wife beta.
- [ ] Ready for wife beta only when blocker/beta-critical items are cleared.

## Retest Result

- [ ] Passed retest.
- [ ] Failed retest.
- [ ] Needs more information.
- [ ] Deferred.
